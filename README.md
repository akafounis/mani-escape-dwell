# Mani Haven

Build a simple, premium, mobile-first landing page for a studio apartment in Mani, Greece.

The page should feel minimal, Mediterranean, warm and architectural — beautiful photography, elegant typography, natural stone/olive/sea tones and subtle animations. Avoid anything that feels like Airbnb, a hotel template, or a SaaS website - no booking mask.

Structure

Keep it to one flowing landing page:

Hero → About the studio → Photos → Location → Book / Contact

Functionality

Large hero image with property name, short description and Book your stay CTA

Beautiful responsive photo gallery with fullscreen lightbox and mobile swipe

Short property description + key amenities

Simple location section with Google Maps

Booking inquiry form: name, email, dates, guests, message

Clear success state after submitting

Phone / email / WhatsApp contact buttons

Sticky Book CTA on mobile

Smooth scrolling and subtle scroll/image entrance animations

Keep the content and UI very simple and focused. The primary goal is for someone to see the place, fall in love with it, and easily send a booking request.

Use placeholder photography/content for now, structured so I can easily replace them later.
